Як працювати з Django

Від встановлення Django до першої сторінки: короткий гайд з командами та поясненням основних понять.

Що таке Django

Django — це вебфреймворк для Python. Він надає готові інструменти для обробки запитів, роботи з базою даних, шаблонами HTML, формами та адміністративною панеллю.

У Django проєкт — це весь сайт і його налаштування, а застосунок (app) — окрема частина сайту з певною функцією. В одному проєкті може бути кілька застосунків.

Встановлення Django

Переконайтеся, що Python встановлений, і створіть папку для нового проєкту. У терміналі перейдіть у цю папку та створіть віртуальне середовище:

          python -m venv .venv

Активуйте його. У Windows PowerShell:

          .\.venv\Scripts\Activate.ps1

У macOS або Linux:

          source .venv/bin/activate

Встановіть Django у віртуальне середовище та перевірте версію:

          python -m pip install Django python -m django --version

Створення та запуск проєкту

Створіть Django-проєкт у поточній папці командою:

          django-admin startproject config . python manage.py runserver

Відкрийте http://127.0.0.1:8000/ у браузері. Локальний сервер зупиняється комбінацією Ctrl + C.

Створіть окремий застосунок для функціональності сайту:

          python manage.py startapp pages

Додайте його до списку INSTALLED_APPS у config/settings.py. Після змін у налаштуваннях або коді перезапустіть сервер, якщо він не перезавантажився автоматично.

Як Django показує сторінку

  1. URL-маршрут у urls.py визначає, яка функція обробить адресу.
  2. Подання (view) у views.py обробляє запит і готує відповідь.
  3. Шаблон у папці templates/ формує HTML, який побачить відвідувач.
  4. Модель (model) описує дані та дає змогу працювати з базою даних через ORM.

Щоб сторінка з’явилася на сайті, зазвичай потрібно створити view, HTML-шаблон і додати маршрут до URL-конфігурації.

Корисні команди Django

python manage.py runserver
Запустити локальний сервер для розробки.
python manage.py startapp назва
Створити новий застосунок у проєкті.
python manage.py makemigrations
Створити файли міграцій після змін у моделях.
python manage.py migrate
Застосувати міграції та оновити структуру бази даних.
python manage.py createsuperuser
Створити адміністратора для панелі /admin/.
python manage.py test
Запустити автоматичні тести проєкту.
python manage.py shell
Відкрити інтерактивну оболонку Django.
python manage.py check
Перевірити проєкт на типові помилки конфігурації.

Якщо змінюєте моделі, типовий порядок такий: makemigrations, потім migrate.

Для чого потрібен Makefile

Makefile зберігає короткі команди (цілі), щоб не набирати довгі команди щоразу. У корені цього репозиторію є цілі:

make run
Запускає локальний сервер: python3 manage.py runserver.
make migrate
Застосовує міграції: python3 manage.py migrate.
make run-server
Запускає сервер на 0.0.0.0:8000, тобто робить його доступним через мережеві інтерфейси комп’ютера. Використовуйте лише коли це потрібно.
make freeze
Записує встановлені Python-пакети у requirements.txt. Перевірте зміни перед збереженням файлу.

Викликати ціль можна командою make назва-цілі, наприклад make run. Для цього має бути встановлений GNU Make. У Windows, якщо Make не налаштований, використовуйте відповідну команду python manage.py ... безпосередньо. У цьому Makefile команди використовують python3, тому перевірте, що така команда доступна у вашій системі.
